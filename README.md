# 드로마스 디스코드 봇

붕괴: 스타레일의 앰포리어스 생물인 **드로마스**를 모티브로 한 디스코드 육성 봇입니다.

## 기능

- `/드로마스입양` : 새 드로마스 입양
- `/내드로마스` : 내 드로마스 목록 확인
- `/드로마스보기` : 드로마스 상태 확인
- `/드로마스먹이주기` : 포만감과 기분 증가
- `/드로마스놀아주기` : 기분과 친밀도 증가
- `/드로마스탐사` : 경험치 획득 및 레벨업
- `/드로마스이름변경` : 이름 변경
- `/드로마스방생` : 버튼 확인 후 삭제
- `/오늘의운세` : 운명의 길 + 속성 운세
- `/도움말`, `/핑`

## 확정된 규칙

- 사용자당 드로마스 최대 5마리
- 이름 제한: 2~10자
- 운세: 사용자당 하루 1회 고정
- 탐사: 드로마스당 하루 3회, 쿨타임 2분
- 놀아주기: 드로마스당 하루 10회, 쿨타임 1분
- 먹이주기: 드로마스당 하루 5회, 쿨타임 1분
- 한국 시간 기준 오전 12시 일일 제한 리셋
- 저장 방식: `data/dromas_data.json`

## 설치 방법

### 1. Python 설치

Python 3.11 이상 권장.

### 2. 패키지 설치

```bash
pip install -r requirements.txt
```

### 3. `.env` 만들기

`.env.example` 파일을 복사해서 `.env`로 이름을 바꾼 뒤, 봇 토큰을 넣으세요.

```env
DISCORD_TOKEN=여기에_봇_토큰
GUILD_ID=테스트서버ID
```

`GUILD_ID`는 개발 중에는 넣는 것을 추천합니다. 해당 서버에 슬래시 명령어가 빠르게 반영됩니다.
비워두면 전역 명령어로 등록되며, 반영까지 시간이 걸릴 수 있습니다.

### 4. 실행

```bash
python main.py
```

## 디스코드 개발자 포털 설정

봇 초대 URL을 만들 때 아래 권한을 체크하세요.

Scopes:

- `bot`
- `applications.commands`

Bot Permissions:

- Send Messages
- Use Slash Commands
- Embed Links
- Read Message History

## 비용 관련

이 코드 자체와 JSON 저장 방식은 돈이 들지 않습니다.
다만 24시간 켜두려면 컴퓨터, 라즈베리파이, Replit, Railway, VPS 같은 실행 환경이 필요합니다.
호스팅 서비스는 무료 제한이 있거나 유료일 수 있습니다.
